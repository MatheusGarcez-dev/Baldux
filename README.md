# Baldux

Landing page de vendas do **Baldux**, balde inteligente para sorveterias.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Motion
- Phosphor Icons
- Manrope Variable

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Imagens

Assets em `src/assets/images/`:

- `bg-hero-1.png` — hero, solução e detalhes do produto
- `baldux-dark.png` — showcase e CTA final
